# Lectures

Приложение для расписания лекций, домашних заданий и локального хранения учебных материалов. В репозитории находятся два самостоятельных проекта: приложение для Windows на Tauri и нативное приложение для Android на Kotlin.

## Проекты

| Каталог | Платформа и технологии |
|---|---|
| [`Lectures/`](Lectures/) | Windows, Tauri 2, Rust и HTML/JavaScript |
| [`LecturesKotlin/`](LecturesKotlin/) | Android, Kotlin и Jetpack Compose |
| [`docs/`](docs/) | Web, HTML/CSS/JavaScript |

У приложений отдельные исходники и сборка. Их можно открывать и выпускать независимо друг от друга.

## Возможности

- Создание лекций с возможностью прикрепить файлы, выбрать дату и предмет;
- Списки лекций по дням или по предметам;
- Домашние задания, сроки сдачи и отметки о выполнении;
- Импорт и экспорт резервной копии в JSON;
- Передача базы данных между устройствами в одной локальной Wi-Fi сети;

Формат JSON-резервной копии совместим между версиями. При сетевом переносе перед заменой данных приложение-получатель создаёт локальную резервную копию.

## Передача данных по Wi-Fi

Подключите оба устройства к одной локальной сети. На устройстве-получателе включите режим приёма данных, затем на источнике укажите адрес и код получателя и отправьте базу. Интернет и облачный сервер для переноса не используются. Приложение должно быть открыто на обоих устройствах.

Для переноса между версиями также можно экспортировать JSON-файл в одном приложении и импортировать его в другом.

**В веб версии нет передачи по Wi-Fi**

# Самостоятельная сборка

## Windows-приложение (`Lectures`)

### Требования

Установите Node.js LTS, Rust stable с MSVC toolchain, Microsoft C++ Build Tools и WebView2. Для первой сборки Windows потребуется интернет для загрузки зависимостей.

### Запуск для разработки

Откройте терминал в каталоге `Lectures`:

```powershell
npm install
npm run tauri dev
```

### Сборка установщика

```powershell
npm run tauri build
```

Собранные файлы Tauri появятся в `Lectures/src-tauri/target/`. В проекте настроен Windows NSIS installer.

## Android-приложение (`LecturesKotlin`)

Откройте каталог `LecturesKotlin` в Android Studio и дождитесь синхронизации Gradle. Требуется JDK 17 и Android SDK для `compileSdk 35`; минимальная поддерживаемая версия — Android 7.0 (API 24).

## Web (`docs`)

Откройте index.html в вашем браузере.
